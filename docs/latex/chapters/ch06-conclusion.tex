\section{对科研数据适用性的实际意义}

对研究者而言，正式发布物比聊天答案更接近可以纳入科研流程的数据对象。它可以直接供脚本读取，具有明确的表结构、来源和质量说明，并可在发现错误时定位和修正。对团队协作而言，发布清单和supersedes关系降低了"每个人手里有一份不同CSV"的风险。

对后续知识图谱、统计分析或证据推理而言，多表关系和溯源提供了比复制宽表更稳定的输入。上述意义成立的前提，是能力边界会随正式产物一并明确交付。

\section{实验结果的关键发现}

第五章的评测实验揭示了三个关键事实：

\textbf{运行终态与字节级验证}。Gold6--10 的 6 个重点运行单元中，5 个形成正式 Publication，gold10 以 \code{blocked\_no\_publication} 结束，运行级发布率为 83.3\%。Gold10 在任务交付层面是未完成，在安全边界层面则证明系统没有把缺少必需差异丰度表的 staging 提升为正式产物。5 个成功运行的当前 Publication 均通过 Artifact 回执与 SHA-256 重验；该结果证明字节完整性和运行绑定，不单独证明科学值正确或需求完整覆盖。

\textbf{效率结果仅作单次观察}。gold1 的四组结果显示，flash 档下 BioMed QAgent 用时和 token 较低，但各实验条件没有重复，且两种环境在提示词附加约束、默认推理参数和运行方式上存在差异，因此不能将成本差异归因于某一单独机制。Gold6 对照组的用量记录不完整，本章只比较其产物覆盖与可审计性。

\textbf{证据可审计性存在差异}。BioMed QAgent 的正式产物具有 Publication 回执、SHA-256、provenance 与 ProductAssessment；Gold6 Qoder 离线导出具有来源列、清单和 QC 日志，但两包均缺少其方法日志引用的 raw payload 与脚本，Flash 清单还有一处自指摘要不一致，Max 的 6{,}439 行只提供 11 个不同 locator。现有检查足以比较审计条件，不能支持“所有单元均无编造值”的全称结论。

\section{核心机制的实际表现}

三项系统贡献（\ref{sec:contributions}节）在评测中都得到验证：

\textbf{可验证产物与完成性绑定的实际表现}。六个重点运行均形成明确终态；gold10 在关键输入不完整时停止且没有正式发布物，其他五个运行的发布物均有可核验回执。本次实验中未出现“没有正式产物却判定成功”的情况。

\textbf{表结构准入控制的实际表现}。gold7 分别形成风险位点与变异--基因映射两个动态数据产品，说明运行时设计的表结构能够在通过准入检查后正式发布。gold9 在固定结构不能满足数据约束后切换到动态数据家族，并完成更新后的发布物。

\textbf{人工确认与证据绑定的实际表现}。gold6 flash 共触发 5 次人工确认，其中 3 次用于受控来源访问授权，2 次用于发布验收；第二次发布明确替代第一次发布并保留版本关系。该结果展示了敏感操作授权和发布验收在同一证据链中的作用。

\section{结论}

BioMed QAgent针对赛题"从科学问题到可用数据"，建立了一条从自然语言需求、来源发现、正式采集、异构解析、字段规范化、多源整合与校验，直到不可变发布的处理链路。

其关键在于把模型放在适合开放式推理的位置。Agent 作为数据产品的设计者提出检索策略、来源选择、多表规格和修正建议；正式数据变更则交给 Dataset Core 的来源绑定、解析、规范化、验证与发布门禁。这一分工降低模型自报或自由生成直接成为正式数据的风险，但不能消除来源错误、解析器缺陷或验证规则覆盖不足，因而仍需 ProductAssessment、来源级抽查与明确的能力边界。

系统把"任务完成"定义为可重验的数据产品。每条正式数据都应说明来源、处理过程、质量状态和不确定之处；收到反馈后，系统可以定位修正并形成可追溯的新版本。这些能力直接对应赛题关于数据质量控制、来源追溯和图表数据提取的要求。

六个重点运行中，5 个形成可逐件校验的正式发布物，1 个在缺少必需输入时拒绝发布。跨环境比较进一步表明，正式发布机制能够提供比普通工作区导出更明确的文件清单、来源绑定和质量状态；由于每个条件只运行一次且部分用量记录不完整，实验不据此推断普遍效率优势。

\textbf{核心贡献总结}：本系统展示了从任务事件、来源资产到 Publication 回执的可检查证据链。六个重点运行单元均留下运行边界内的事件记录，其中 5 个当前 Publication 的产物逐件通过回执与 SHA-256 重验，gold10 则在必需表缺失时保持未发布。该机制把候选准入与模型自报分离；其已验证范围是字节完整性、运行绑定和确定性门禁，科学真实性与需求覆盖仍需来源级和任务级评估。
