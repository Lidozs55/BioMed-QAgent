\section{对科研数据适用性的实际意义}

对研究者而言，正式发布物比聊天答案更接近可以纳入科研流程的数据对象。它可以直接供脚本读取，具有明确的表结构、来源和质量说明，并可在发现错误时定位和修正。对团队协作而言，发布清单和supersedes关系降低了"每个人手里有一份不同CSV"的风险。

对后续知识图谱、统计分析或证据推理而言，多表关系和溯源提供了比复制宽表更稳定的输入。上述意义成立的前提，是能力边界会随正式产物一并明确交付。

\section{实验结果的关键发现}

第五章的评测实验揭示了三个关键事实：

\textbf{运行终态与字节级验证}。主评测包含 gold6--10 flash 与 gold6 max v2 共 6 个运行单元，其中 5 个形成正式 Publication，gold10 以 \code{blocked\_no\_publication} 结束，观察到的发布率为 83.3\%。Gold10 在任务交付层面是未完成，在安全边界层面则证明系统没有把缺少必需差异丰度表的 staging 提升为正式产物。5 个成功运行的当前 Publication 均通过 Artifact 回执与 SHA-256 重验；该结果证明字节完整性和运行绑定，不单独证明科学值正确或需求完整覆盖。

\textbf{效率结果仅作单次观察}。gold1 的既有四组记录在 flash 档显示 BioMed QAgent 用时和 token 较低，但各单元没有重复，跨环境提示词、默认推理参数与运行驱动也不同，不能把差异因果归因于治理工具。Gold6 的已提交 Qoder 离线证据包不含可独立核验的时长和 token 导出，因此本报告只比较其产物结构与证据可审计性，不再沿用旧效率比值。

\textbf{证据可审计性存在差异}。BioMed QAgent 的正式产物具有 Publication 回执、SHA-256、provenance 与 ProductAssessment；Gold6 Qoder 离线导出具有来源列、清单和 QC 日志，但两包均缺少其方法日志引用的 raw payload 与脚本，Flash 清单还有一处自指摘要不一致，Max 的 6{,}439 行只提供 11 个不同 locator。现有检查足以比较审计条件，不能支持“所有单元均无编造值”的全称结论。

\section{核心机制的实际表现}

三项系统贡献（\ref{sec:contributions}节）在评测中都得到验证：

\textbf{可验证产物与完成性绑定的实际表现}。早期对抗测试曾暴露自然语言自报与正式产物脱节的问题。corrected 主评测的 6 个运行均有终态事件；gold10 明确阻断且没有 Publication，其他 5 个运行的当前 Publication 均有可核验回执。这说明本批次中未观察到“无正式产物却判成功”的情况，但不外推为对所有模型与任务的绝对保证。

\textbf{表结构准入控制的实际表现}。corrected gold7 形成风险位点与变异--基因映射两个独立动态 Publication；当前证据不支持把它写成一个三表产品或 11 轮拒绝--修正。gold9 的 durable route 在动态准备成功后从 static 更新为 dynamic family，并产生 v1、v2 两个 Publication；两者 \code{supersedes\_publication\_id} 均为空，故只能说 v2 成为 current，不能声称形成正式 supersedes 换版链。权限挂起后的继续运行也不等同于已证明 Dataset Core checkpoint replay。

\textbf{人工确认与证据绑定的实际表现}。gold6 flash 的 5 次 HIL 由 3 次 exact-only credential 授权和 2 次发布验收组成；证据没有记录低置信度点值人工修正。其第二个 Publication 明确 supersedes 第一个 Publication。Gold7 的两个 Publication 则均没有 supersedes 关系，不能作为换版链实例。

\section{结论}

BioMed QAgent针对赛题"从科学问题到可用数据"，建立了一条从自然语言需求、来源发现、正式采集、异构解析、字段规范化、多源整合与校验，直到不可变发布的处理链路。

其关键在于把模型放在适合开放式推理的位置。Agent 作为数据产品的设计者提出检索策略、来源选择、多表规格和修正建议；正式数据变更则交给 Dataset Core 的来源绑定、解析、规范化、验证与发布门禁。这一分工降低模型自报或自由生成直接成为正式数据的风险，但不能消除来源错误、解析器缺陷或验证规则覆盖不足，因而仍需 ProductAssessment、来源级抽查与明确的能力边界。

系统把"任务完成"定义为可重验的数据产品。每条正式数据都应说明来源、处理过程、质量状态和不确定之处；收到反馈后，系统可以定位修正并形成可追溯的新版本。这些能力直接对应赛题关于数据质量控制、来源追溯和图表数据提取的要求。

主评测说明该设计在当前六个异质运行单元中可落地：5 个运行形成字节可重验的 Publication，1 个运行在缺少必需输入时拒绝发布。由于提示词来源、路线、HIL 暴露和 Host 条件不同，这一结果不是模型排名。跨环境材料进一步表明，正式 Publication 能提供比普通工作区导出更强的字节绑定；但现有单次、混杂设计与不完整的外部 usage 证据不足以证明普遍效率优势。

\textbf{核心贡献总结}：本系统展示了从任务事件、来源资产到 Publication 回执的可检查证据链。主评测六个运行单元均留下运行边界内的事件证据，其中 5 个当前 Publication 的产物逐件通过回执与 SHA-256 重验，gold10 则在必需表缺失时保持未发布。该机制把候选准入与模型自报分离；其已验证范围是字节完整性、运行绑定和确定性门禁，科学真实性与需求覆盖仍需来源级和任务级评估。
