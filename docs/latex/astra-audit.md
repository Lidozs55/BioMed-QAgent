## 一、提交前必须修正的问题

### 1. 样例6“效率优势”的论证不成立

**位置：第五章“总体比较”“主要发现”，第六章“轻量模型效率优势”。**

正文反复强调：Qoder 交付量不小于本系统，所以本系统较低运行成本与交付规模无关。可是同章评分显示，样例6 flash 下，本系统需求覆盖为 **3.5/6**，Qoder 为 **5.5/6**；本系统图系列、图点两表均为空，补充材料登记表也为空。

这里推论方向恰好相反：

> **对方完成更多内容、花费更多成本，不能排除工作量差异；反而说明工作量差异仍然存在。**

本系统可能确实更高效，但现有实验无法区分“执行更高效”与“完成内容更少”。记录行数也不能直接代替工作量：检索一篇补充材料、识别一张图、下载一万条数据库记录，并非同等任务。

**建议直接替换相关结论：**

> 在样例6的单次 flash 运行中，BioMed QAgent 的记录时长与 token 总量低于 Qoder，但需求覆盖评分也较低。由于交付内容、计量方式与完整推理配置尚未统一，本实验仅呈现两套系统在成本与覆盖之间的取舍，不能据此判定同等任务下的效率优势，也不能将成本差异归因于确定性管线。

这段修改不影响你们展示实际成本，只撤回当前证据无法支持的结论。

### 2. 必须区分“发布成功”与“原始需求完成”

**位置：第五章评测方法、十案例总表，第六章实验总结。**

你们已经说明“文件摘要一致不能替代科学内容核验”，这条边界应该保留。但完成性指标仍主要依据是否形成正式发布物。直接证据显示：

* 样例4正式交付只有两行蛋白注释，原任务却涉及结构、序列与变异证据。
* 样例6正式发布九件产物，但部分任务所需数据表为空。
* 样例8实验报告明确说明：只有 FAERS 断言与研究数据进入正式发布，其余请求维度仍停留在暂存层。

因此，“成功发布”作为**软件运行终态**没有问题；但它不能单独回答“科研需求完成了多少”。

这里还有一个更根本的问题：**Agent 自己选择来源、制定执行规格，再通过这个规格对应的发布检查，不代表它完整保留了用户原始需求。** 即使系统严格执行规格，也可能出现“执行正确，但规格已经缩小任务范围”。

建议十案例总表至少拆成两列：

| 指标       | 回答什么                  |
| -------- | --------------------- |
| 正式发布状态   | 有没有通过系统发布检查的交付物？      |
| 原始需求完成情况 | 原任务中哪些要求已完成、部分完成、未完成？ |

样例8应明确标注“正式发布成功，需求部分完成”；样例6应直接标出图表数值与补充材料缺口，而不是只在后面细读才能发现。

**不必取消发布率，但应始终称“运行级正式发布率”，不要让它承担任务完成率的含义。**

### 5. 哈希重验不能验证“同规格重跑逐字节复现”

**位置：第一章确定性核心贡献，第六章机制验证。**

第六章用“全部正式产物逐件 SHA-256 重验一致”支持“结果可复现”。但重读同一份文件，确认摘要与清单一致，验证的是**文件完整性与回执匹配**；重新执行处理流程后生成相同输出，才是在验证**跨次执行可复现性**。这是两种不同实验。

另外，仅固定执行规格也不够。来源响应可能变化，模型抽取可能变化，动态变换实现、依赖版本、记录排序、生成时间等也可能影响最终字节。第四章已经承认动态代码准入不检查语义正确性，这意味着“独立校验”也不能自动证明数值正确。

建议将现有结论改成：

> 本轮验证了正式发布文件与其回执之间的一致性。跨次执行的字节一致性尚未单独评测；相关复现实验需要冻结来源资产、执行规格、变换实现、模型抽取结果与运行环境，并明确哪些文件参与一致性比较。

**可追溯、文件未变、处理可重放、结果正确，应当分开论证。** 不要让“可信”一个词同时承担四种含义。

### 7. 相关工作比较过于绝对，容易形成“稻草人”

DocETL 的论文也明确提出任务相关验证提示与计划评估机制。它是否提供你们关注的确定性发布协议，可以进一步比较；但应明确区分**模型质量评估**与**确定性发布检查**，不能用一句“不经过独立校验”概括。([arXiv][2])

更稳妥的贡献表述是：

> 本系统将来源资产登记、候选准入、发布前检查、证据绑定审批与消费时重验组合为面向科研数据产品的统一交付协议。本文重点验证这些环节在同一任务中的协同执行，而非声称通用框架无法实现相似约束。

另外，第六章称“纯人工整理”和“纯 Agent 问答”为基线，实际第五章却比较 Qoder，且没有人工整理实验。这里应改为**概念性对照**或“预期收益与新增开销”，不能让读者以为你们测量过人工基线。Qoder 已经交付数据包、方法日志与质量检查，也不能再概括为一次问答。

图表部分也应缩小措辞。第四章描述的轴与图例规则主要检查**模型声明与点数据是否一致**，并明确承认：模型错误声明“含义明确”时，该规则无法识别。这应称为“图表证据一致性检查”，不能直接等同于独立识别坐标轴、图例解析错误。
