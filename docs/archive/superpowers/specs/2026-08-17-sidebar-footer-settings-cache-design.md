# 侧栏底部精简与缓存导出入口设计

## 目标

侧栏底部仅保留“设置”入口，移除连接状态、并发槽位和缓存导出入口。缓存导出能力继续由“设置 → 常规 → 本地数据”提供。

## 设计

- 删除 `SessionSidebar` 对连接状态、占用槽位和缓存导出回调的读取与渲染。
- 设置入口使用与历史任务行相同的 `SidebarMenu`、`SidebarMenuItem` 和 `SidebarMenuButton` 组合。侧栏内容组和底部区域均使用 `p-2`，按钮也共享同一组件内边距，因此两处图标位于同一垂直列。
- `App` 不再向侧栏传递缓存导出回调；现有 `SettingsPanel` 回调和 `/api/v1/cache/export` 下载流程保持不变。
- 不修改服务端缓存导出格式、设置导航结构或通用 Sidebar 原语。

## 验收

- 侧栏底部不显示连接状态、并发槽位或导出缓存。
- 设置按钮仍可打开设置，并与历史记录图标水平对齐。
- 设置页“常规”分区仍显示“导出缓存”，点击后调用导出回调。
- 前端测试、lint、类型检查和构建通过；正式根启动入口可在 `8001` 端口运行。
