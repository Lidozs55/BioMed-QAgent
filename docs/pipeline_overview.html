数据源

活跃数据源（15 个模块函数）
  • 文献检索：PubMed、Europe PMC（国内可用，OA 文献）、OpenAlex、Semantic Scholar
  • 蛋白质/基因：STRING（PPI）、DisGeNET（基因-疾病）、UniProt、PDB（结构）
  • 化合物/药物：TCMSP（中药成分）、DrugBank、PubChem
  • 通路：KEGG、Reactome
  • 其他：citation_trace（引用追溯）、web_crawler（网页爬取）

关键设计决策

🔄 方案A隐性循环 vs 旧版多轮迭代

旧版：每轮跑完整 6 阶段 + IterationDecisionAgent 决策，冗余且"补齐原计划 gap"而非"扩展研究边界"。

新版：单轮完整流水线后，Reviewer 识别报告薄弱点，生成精准追查任务，仅跑 search→parse + 重跑分析。 IterationDecisionAgent 已移除（-479 行），架构更简洁。

📝 query_log 全局记录

SearchAgent 每个查询执行后记入 context["query_log"]（含 query/source/phase/status/records_count）。 第一轮 + followup 都记录，压缩后传给 Reviewer，使其能判断"已尝试但未找到"，在报告中标注 + 避免重复追查。

🌐 国内网络适配

  • Unpaywall API 不可达 → 5s 超时 + 3 次失败禁用 + EPMC fullTextXML fallback
  • OpenAlex/Semantic Scholar 429 限流 → Europe PMC 作为国内可用的 OA 文献源
  • PMC PDF 直链反爬 → 改用 EPMC fullTextXML API 获取 JATS XML 全文

⚡ 性能优化

  • AnalysisAgent：Phase1（PPI/富集/药物靶点/差异表达）asyncio.gather 并行；Phase2（Hub/上游调控）复用 PPI 结果
  • API timeout 从 120s 降至 30s，避免单点卡死
  • uvicorn --reload 模式，代码变更自动重载
