# BioMed-QAgent 开发 TODO

## 0. 项目目标与范围

### 0.1 核心目标

构建一个面向生物医学科研场景的数据整合智能体，使用户能够通过自然语言描述研究目标，系统自动完成：

1. 理解数据需求；
2. 制定数据检索与处理计划；
3. 查找论文、数据库、附件、表格等数据源；
4. 提取原始数据；
5. 清洗、去重、字段对齐和单位统一；
6. 记录来源和处理过程；
7. 输出统一结构化数据文件；
8. 在出现低置信度或异常时请求人工确认并重新修正。

### 0.2 主要交付物

- 可交互前端页面；
- 可调用测试 API；
- 代表性测试案例；
- 合并后 CSV 或 Parquet 数据；
- 字段说明文件；
- 来源清单；
- 数据处理日志；
- 技术报告；
- 完整源码；
- 不超过 20 页的答辩 PPT/PDF；
- 可选演示视频。

### 0.3 暂不优先实现

- 完整科研报告自动生成；
- 深度科研假设推理；
- 复杂知识图谱分析；
- 科研影响力预测；
- 大规模模型微调；
- 全自动处理所有未知网站；
- 无人工干预的复杂图表识别；
- 高并发、多租户商业化部署。
