# BioMed-QAgent 开发 TODO

## 0. 项目目标与范围

### 0.1 核心目标

构建一个面向生物医学科研场景的数据整合智能体，使用户能够通过自然语言描述研究目标，系统自动完成：

1. 理解数据需求；
2. 制定数据检索与处理计划；
3. 查找论文、数据库、附件、表格等数据源；
4. 提取原始数据；
5. 清洗、去重、字段对齐和单位统一；
6. 记录来源和处理过程；
7. 输出统一结构化数据文件；
8. 在出现关键质量问题或语义歧义时请求人工确认并重新修正。

### 0.2 主要交付物

- 可交互前端页面；
- 可调用测试 API；
- 代表性测试案例；
- 作为主要数据产物的标准 CSV 文件；
- 可选的 Excel、Parquet 或 JSON 辅助产物；
- 字段说明文件；
- 来源清单与来源获取状态记录；
- 数据处理日志与异常记录；
- 技术报告；
- 完整源码；
- 不超过 20 页的答辩 PPT/PDF；
- 可选演示视频。

## 5. 第四阶段：Tool 系统

### 5.0 Tool 的职责边界

- [ ] **P0** 将 Tool 定义为可独立调用的原子能力
  - 输入和输出必须明确；
  - 操作尽量确定、可测试、可重放；
  - 不包含跨多个步骤的业务流程；
  - 不负责决定下一步调用哪个 Tool；
  - 不直接调用 Skill。

- [ ] **P0** 规定调用方向

```text
Main Agent / Sub Agent
        ↓
      Skill
        ↓
      Tool
        ↓
Service / Repository / Storage / External Source
```

- [ ] **P0** 简单且单步的原子任务允许 Agent 直接调用 Tool
- [ ] **P0** 涉及检索策略、多个数据源、解析、清洗或审核的任务必须优先通过 Skill 编排 Tool
- [ ] **P0** Skill 只组合和约束 Tool，不重复实现 Tool 内部逻辑

- [ ] **P0** 一般格式修复、大小写统一、明确单位转换等确定性操作无需逐项确认，但必须记录变换
