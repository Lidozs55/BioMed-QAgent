# Artifact Samples

This directory ships **real pipeline outputs** so reviewers can inspect the
actual artifact format without running the pipeline.

## `gse178352/`

A complete validated artifact package generated by running the pinned
GSE178352 fixture through the deterministic pipeline (Discovery →
Acquisition → Processing → Artifact Build → Validation).

| File | Purpose |
| --- | --- |
| `run_manifest.json` | Terminal run manifest — task state, validation status, stage attempts, artifact manifest |
| `main_data.csv` | Main expression matrix (gene × sample) with 22 fixed columns |
| `literature.csv` | PubMed literature records linked to the dataset |
| `dataset_catalog.csv` | Dataset registry (GSE178352 entry) |
| `sample_metadata.csv` | Per-sample metadata (cell line, treatment, etc.) |
| `field_descriptions.csv` | Human-readable field descriptions for each column |
| `field_mapping.csv` | Source-to-output field mapping traceability |
| `source_list.csv` | Data sources used (GEO, PubMed) |
| `source_relations.csv` | Relations between sources (e.g. PMID ↔ GSE) |
| `source_assets.csv` | Downloaded asset files |
| `download_log.csv` | Per-asset download log with status |
| `processing_log.csv` | Processing steps with warnings |
| `quality_report.csv` | Validation gate results |
| `warnings.csv` | Cell-line normalization and other warnings |

## Regeneration

To regenerate the samples (e.g. after a pipeline change), run the pinned
fixture pipeline manually:

```python
import asyncio
from pathlib import Path
from app.pipeline.runner import PipelineRunner

FIXTURE_DIR = Path("tests/fixtures/ncbi/gse178352")
runner = PipelineRunner(
    task_id="task_sample",
    base_dir=Path("/tmp/tasks"),
    fixture_dir=FIXTURE_DIR,
)
asyncio.run(runner.run())
# artifacts are at /tmp/tasks/task_sample/artifacts/
```

The samples here were generated on 2026-07-20 from the GSE178352 fixture.
