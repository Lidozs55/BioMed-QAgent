# 研究问题 → 数据策略与设计

承接索引页。任何科研数据任务开始时的第一步：把用户请求转成简短的内部分析契约，再据此
选择数据源与数据集。本主题不重复构建机制（见主提示），只给策略与设计判断。

## 1. 先冻结分析契约

处理数据前在内部确认并记录（不写给用户）：

- **研究设计**：实验/观察、横断/纵向、配对/重复测量；
- **独立分析单位**：患者、样本、基因×样本——"一行代表什么"；
- **关键时间点**：时间零点、随访/暴露/结局顺序；
- **主要变量/比较**：暴露/处理、主要与次要结局、分组（tumor vs normal 等）；
- **目标与交付物**：差异表达表？基因级表达矩阵？临床队列可用性报告？

定义不足时采用保守口径或并列场景，继续完成所有可靠部分并在同一轮交付；待确认事项只
说明影响，不得成为暂停构建的门槛。

## 2. 常见研究主题 → 数据策略

| 研究主题 | 主数据路径 | 补充证据路径 |
|---|---|---|
| 单基因/靶基因表达差异（如 METTL5 在肿瘤 vs 癌旁） | **GDC/Xena 基因级 RNA-seq 矩阵**（TCGA 等，gene symbol/ENSG 直接可查，无需 probe→gene）；GEO 微阵列作配对设计验证 | PubMed 文献证据 |
| 全转录组差异表达（疾病 vs 正常） | GEO 系列矩阵（microarray）或 GDC/Xena 基因级 | PubMed；差异基因通路富集调研（Reactome） |
| 共病/多表型关联 | X 侧 + Y 侧分别检索，再查共享机制 | 综述提取候选通路；"gene+X"/"gene+Y" 双向证据 |
| 药物靶点发现 | 基因→化合物→通路三角：PubChem 查化合物、Reactome 查通路、GEO 查表达 | GDC/Xena 表达验证 |
| 生物标志物筛选 | GDC/GEO 表达构建 + PubMed 证据 | Xena 独立队列 |
| 通路网络分析 | Reactome 通路成员调研 + GEO/GDC 表达构建（Reactome 不进正式构建） | PDB 结构佐证 |
| 临床队列可用性/治疗比较 | 临床/EHR/试验数据（见 `clinical` 主题） | 文献 |

主题不互斥，必要时组合。

## 3. 分组与配对设计充分性

- 差异分析至少需要 **2 个可比较的组**（如 tumor vs normal），且样本量足以支撑目标分析；
  单组/单样本数据只能产出"该样本表达谱"，**不能回答组间差异**——此时应换数据集，或在
  交付中明确说明目标不可达。
- 配对设计（同一患者的肿瘤/癌旁）比非配对更能控制混杂；选择数据集时优先配对设计。
- 数据集选择与目标脱节时（如选了机制研究芯片但目标是单基因差异），说明价值在于提供
  配对矩阵，但需自行判断 probe 级产物是否可回答目标问题。

## 4. 数据源选择原则

- **单基因/靶基因差异**：优先基因级矩阵（GDC/Xena），避免 probe→gene 映射缺失风险；
- **微阵列配对设计**：GEO series_matrix；
- **蛋白结构/通路/化合物**：PDB / Reactome / PubChem（research-only，不进正式构建）；
- **被保护来源**（需登录/API key/付费）：不要尝试访问，请求用户授权。

## 5. 保守口径与可分析性

- 数据只覆盖部分对象时，只分析被数据支持的部分，不用无关代理数据补齐范围；
- 多数据集只有在人群、时间、结局和特征定义可比时才合并；无法个体级连接的数据用于
  跨队列比较或互证，不作行级合并；
- 在进入构建前回答：**"已查询数据源：[列出]；未查询但相关的：[列出或'无']"**；
  对每个候选数据集判断"这份数据能否回答用户的问题"，不能回答就换或并列说明。
