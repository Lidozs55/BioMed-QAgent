# 科研数据策略指导（索引）

> 本技能为 BioMedQAgent 提供分专题的科研数据获取/整合指导。职责边界：**数据查找、解析、
> 清洗、整合与可分析性判定**——统计建模与可视化由用户/下游承担，不在本技能范围。
> 使用方式：直接调用 `get_research_data_guidance(topic=...)`，
> arguments={"topic": "<主题>"})`，只读取与当前问题相关的主题，不全部加载。

## 主题路由

| 场景 | topic | 何时读取 |
|---|---|---|
| 研究问题 → 数据策略与设计、数据源选择、分组/配对设计、证据路径 | `strategy` | 任何科研数据任务开始时 |
| 表达谱差异分析、RNA-seq vs 微阵列、基因级 vs probe 级、TCGA/GDC/Xena/GEO、其它组学（甲基化/突变/蛋白组等）数据获取 | `expression_omics` | 课题涉及表达谱或组学数据 |
| 临床队列、EHR/试验数据、tumor/normal、时间零点、编码映射、缺失语义 | `clinical` | 课题涉及临床/试验/队列数据 |
| 蛋白结构（PDB）、通路网络（Reactome）、化合物（PubChem）检索 | `structure_pathway_compound` | 课题涉及结构/通路/化合物/药物靶点 |
| 实体映射（probe→gene、symbol→ensembl）、单位/语义/尺度、缺失/重复、可分析性判定 | `cleaning` | 构建前评估数据可分析性，或构建结果异常时 |
| 溯源闭包、多源整合实体一致性、不可变发布、复现契约 | `reproducibility` | 多源整合、发布或复现类任务 |

## 通用原则（所有主题共守）

- **同轮推进**：定义不足时采用保守口径（保留原值、不擅自映射、不把未知当正常），
  完成所有仍可可靠完成的检索与构建，再用"已确认 + 条件性 + 未决影响"表达不确定性；
  不得把待确认事项作为暂停构建的门槛。
- **原始数据不可改写**：下载的文件只读；清洗/修正发生在派生副本并可追溯。
- **一行代表什么**：先确定独立分析单位（患者/样本/基因×样本），不要把事件、孔、细胞
  等下层记录当作独立样本量；差异分析的分组（tumor vs normal）必须 ≥2 组且设计匹配。
- **机制驱动而非关键词驱动**：先从综述/文献提取候选机制与基因，再按具体实体查询
  结构/通路/化合物库，最后进入表达构建。
- **构建纪律**：正式产物仅由 `execute_dataset_build` 生成；先 `validate_dataset_build_spec`
  预检，不把不同 family/granularity 的数据塞进同一 spec。
